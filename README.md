# OMNİYAYI-N-

Türkiye kanallarını kategorilere ayıran canlı yayın rehberi. Yayınlar sitenin içinde oynatılmaz; her kanal kendi resmi sayfasına gider.

## Açılış

`index.html`

## Bu turda düzelenler

- Olmayan `favicon.png` yerine `favicon.svg`.
- Olmayan `profile.html` eklendi; profil menüsü artık 404 vermez.
- Kırık `https://cdn/...` logoları ve kapanmış placeholder servisi yerine harf avatari. Hata olursa ikinci kez istek atılmaz.
